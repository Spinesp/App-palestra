# App Palestra

Web app personale (PWA) per seguire le schede in palestra dall'iPhone: si apre da Safari e si aggiunge alla schermata Home.

- Funziona offline e tiene i dati solo sul telefono.
- Il programma di allenamento e lo storico **non** sono in questo repository: si caricano al primo avvio da un file privato (`app-palestra-dati.json`).
- Backup ed esportazione per Excel dalle Impostazioni dell'app.
